## ✨ 機能特性

- ゲームインターフェース＆ストーリーの翻訳
- ゲーム内の動的モザイクを無効化
- ゲーム起動時の音量案内をスキップ
- ストーリーキャラクターの音声が途切れないようにする
- ゲーム起動時のタイトルアニメーションを無効化
- `Ctrl` キーを押したままマウスホイールを操作してストーリー用 Live2D のサイズを調整

## 🚀 すぐに始める

### 1. ゲームクライアントのインストール

DMM Game Player版のゲームがインストールされており、ゲームの実行ファイルが存在するディレクトリを把握していることを確認してください。

### 2. プラグインのダウンロード

[Releases](https://github.com/anosu/AbyssMod/releases) ページに移動し、最新バージョン（緑色の「Latest」マークが付いているもの）を探して、「Assets」を展開し、「AbyssMod.7z」圧縮ファイルをダウンロードしてください。

> ⚠️ `Source code`はダウンロードしないでください。それはソースコードです。

### 3. インストール

圧縮ファイルをゲームのルートディレクトリ（ゲームの`.exe`と同じ階層）に解凍すると、解凍後のディレクトリ構造はおおよそ次のようになります：

ゲームのルートディレクトリ/
├── ゲーム.exe
├── winhttp.dll
└── BepInEx/
    ├── core/
    ├── plugins/
    │   └── AbyssMod/
    └── config/

### 4. ゲームの起動

**通常通りゲームを起動する**（DMMPlayerから起動します）。これが初めてBepInExをインストールする場合、起動時に現在のUnityバージョンに対応したパッチが自動的にダウンロードされ、その間はコンソールウィンドウが1つだけ表示されます。少々お待ちいただければすぐに終了します。

> ⚠️ ACGPなどのアクセラレータを使用している場合、コンソールに赤色のエラーが表示されることがあります。これはBepInExの公式サイトに直接接続できていない可能性があるため、プロキシ/ランプを有効にしてから再試行してください。

### 5. 設定ファイル

初回実行後、`BepInEx\config\` ディレクトリに2つの設定ファイルが生成されます：

| ファイル         | 用途                                 |
| -------------- | ------------------------------------ |
| `BepInEx.cfg`  | BepInExフレームワークの設定（コンソールウィンドウの非表示など） |
| `AbyssMod.cfg` | プラグイン機能の設定（翻訳、フォント、モザイクなど） |

## ⚙️ 設定項目

### `[General]`

| 設定項目                | デフォルト値 | 説明                 |
| ----------------------- | ------- | -------------------- |
| `DynamicMosaic`       | `false` | 動的モザイクを有効にするか |
| `SoundCaution`         | `false` | 音量警告を表示するか   |
| `VoiceInterruption`   | `false` | 音声中断を有効にするか |
| `TitleMovie`          | `true`  | タイトルアニメーションを再生するか |
| `NovelLive2DScale`    | `1.0`   | ストーリーLive2Dの拡大率（範囲 `0.1` ～ `10.0`） |

### `[Translation]`

| 設定項目     | 選択可能な値                                   | デフォルト値                                                                                      | 説明                                                                    |
| ---------- | -------------------------------------------- | ------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| `Enabled`  | `true`（有効）、`false`（無効）              | `true`                                                                                      | ゲーム内のストーリー翻訳を有効にするかどうか                                        |
| `CDN`      | 有効なCDN URLアドレスのいずれか                  | `https://raw.githubusercontent.com/anosu/dotabyss-translation/refs/heads/main/translations` | 翻訳データのCDNアドレス                                                     |
| `Language` | `zh_Hans`（簡体中国語）                        | `zh_Hans`                                                                                   | 翻訳言語。`zh_Hans`の簡体中国語がサポートされています |

### `[Translation.Font]`

| 設定項目            | デフォルト値               | 説明                                                |
| ----------------- | -------------------------- | --------------------------------------------------- |
| `AssetBundlePath` | `AbyssMod/fonts/ttcuyuanj` | TMPフォントのAssetBundleパス（プラグインディレクトリを基準とした相対パス、または絶対パス） |

## ❓ よくある質問

<details>
<summary><b>起動時にコンソールウィンドウに赤いエラーメッセージが表示される</b></summary>
これは通常、BepInExが公式サイトからUnityパッチをダウンロードできないためです。プロキシ/サーバーを有効にしてゲームを再起動してください。

初期化ファイルがネットワークの不安定さによりダウンロードされたファイルが破損している可能性もあります。その場合は、Modファイルを削除してから再インストールしてみてください。

</details>

<details>
<summary><b>コンソールウィンドウを非表示にする方法</b></summary>
<code>BepInEx\config\BepInEx.cfg</code> を編集し、<code>[Logging.Console]</code> を探して <code>Enabled</code> の値を <code>false</code> に設定します。
</details>
